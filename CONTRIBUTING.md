# Como contribuir

Obrigado pelo interesse em contribuir com o Conversor de Moedas.

## Preparando o projeto

1. Faça um fork do repositório.
2. Clone o seu fork.
3. Crie uma branch para a alteração: `git checkout -b minha-alteracao`.
4. Execute os testes antes e depois de modificar o projeto.

## Enviando uma alteração

Mantenha cada contribuição focada em um único objetivo. Use nomes claros, preserve o comportamento existente e inclua testes quando adicionar ou corrigir uma funcionalidade.

Depois de validar a alteração, envie a branch para o seu fork e abra um pull request descrevendo o problema e a solução proposta.

## Testes

```bash
python -m unittest discover -s tests -v
```
